# ADR-0032: Name: surrealmem

- **Status:** Accepted
- **Date:** 2026-10-02
- **Deciders:** Derek Damko

## Context

The name appears in the package, CLI, MCP tool listings, units and repository.

## Decision

Package, CLI and MCP server are `surrealmem`; the repository is `surreal-mem`.

## Consequences

Descriptive and searchable; a product name can be layered on later.
