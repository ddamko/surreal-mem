# ADR-0021: Eight dashboard pages in a fixed order

- **Status:** Accepted
- **Date:** 2026-10-02
- **Deciders:** Derek Damko

## Context

The brief names the graph, the vectors, querying and relationship analytics explicitly.

## Decision

Build Overview, Graph Explorer, Retrieval Playground, Conversations, Analytics, Vector Space, Curation and Operations, in that order, each usable before the next starts.

## Consequences

Pages needing the least data land first while the system fills.
