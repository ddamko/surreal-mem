# ADR-0030: Dark observatory visual direction

- **Status:** Accepted
- **Date:** 2026-10-02
- **Deciders:** Derek Damko

## Context

Graph canvases and heatmaps read best on dark surfaces; six type hues need a quiet background.

## Decision

A custom daisyUI 5 theme on near-black surfaces with one cool accent and a switchable light variant; Inter for text, JetBrains Mono for identifiers and SurrealQL; one fixed hue per base entity type used everywhere; relationship kinds in neutrals. The palette is validated for contrast in both variants.

## Consequences

Consistent visual language across canvas, charts, badges and legends.
